# CardSurface

SUI's card: the bordered surface a role card and most panels sit on.

Other variants: `FillCardSurface`, `CompactSurface`, `InteractiveCard`, `InfoSurface`, `SuccessSurface`, `WarningSurface`, `DangerSurface`, `NoteCard`, `WideCard`, `SplitCard`, `PopoverSurface`, `NoticeBar` and more. The theme owns every colour; a surface only picks a tone.
