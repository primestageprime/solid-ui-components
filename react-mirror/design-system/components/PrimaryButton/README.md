# PrimaryButton

SUI's primary action button; every button in SUI is a named variant like this one.

The variants: `DefaultButton`, `PrimaryButton`, `SecondaryButton`, `DangerButton`, `WarningButton`, `GhostButton`, `OutlinedButton`, `TextButton`, `IconOnlyButton`, the `Small…` and `Large…` sizes, `QuietDangerButton`, and the glyph-slot buttons the dials use (`GlyphSlotGhostButton`, `ReservedGlyphSlotButton`, `DisclosureButton`, `PressableLabelButton`).

- `disabled`, `loading` (disabled with a spinner), `active`, `type` (defaults to `button`), and any button attribute.

Controls in one row share one height: put a small button next to small controls, never a default one.
