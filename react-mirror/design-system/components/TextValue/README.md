# TextValue

The large figure in SUI's type scale; all text in SUI is a named Text variant like this one.

The scale: `TextValue` 1.5rem/600, `TextLabel` 1rem/600, `TextTitle` 0.875rem/600, `TextBody` 0.875rem, `TextUnits` 0.9rem, `TextSublabel` 0.75rem. Toned and mono variants (`DangerBody`, `MonoValue`, `MonoMeta`, `EllipsisLabel` and others) build on it.
